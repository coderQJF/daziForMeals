# Asset destinations

| Purpose | Destination |
|---|---|
| Home actions and header icons | `frontend/src/static/images/home/` |
| Category icons and covers | `frontend/src/static/images/category/<group>/` |
| Plan UI and meal images | `frontend/src/static/images/plan/` |
| Plan detail icons | `frontend/src/static/images/plan-detail/` |
| Recommendation actions | `frontend/src/static/images/recommendation/` |
| Recipe detail controls | `frontend/src/static/images/recipe-detail/` |
| Reusable recipe photos | `frontend/src/static/images/recipes/` |
| Favorite/kitchen UI | `frontend/src/static/images/favorite/` |
| User/profile UI | `frontend/src/static/images/user/` |
| TabBar normal/active pairs | `frontend/src/static/tabbar/` |

Naming examples:

- `icon-bell.png`
- `action-refresh.png`
- `filter-leaf.png`
- `yam-pork-rib-soup-hero.jpg`
- `home-active.png`
